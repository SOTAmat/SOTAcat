SOTAcat USB Firmware Installer

Install the latest SOTAcat firmware over a USB cable, straight from this page.

Requirements

  • A desktop browser: Google Chrome, Microsoft Edge, or Opera. Phones and tablets cannot do this - Web Serial does not exist on iOS or Android.
  • A USB data cable connecting the SOTAcat to this computer.
⚠️ USB flashing is a factory reset. It erases all settings on the device: WiFi networks, callsign, everything. If your SOTAcat already works and its Settings page has a Firmware section, update over the air instead and keep your settings - see Updating Firmware. This page is for first-time installs, recovery, and devices too old to update themselves.

Your current browser does not support installing SOTAcat firmware via USB. You must use desktop Google Chrome, Microsoft Edge, or Opera - or flash from the command line instead: USB Flashing guide.

You must connect to this web page over secure HTTPS (not insecure HTTP) in order to install SOTAcat firmware. Change your browser URL and try again.

If the device doesn't show up

  • Charge-only USB cables are the #1 culprit. Many USB cables carry power but no data. If no serial port appears in the picker, try a different cable.
  • The SOTAcat sleeps after about 60 seconds of inactivity. If it has been sitting idle, power-cycle it just before clicking the install button.

After installing

The device reboots as a fresh SOTAcat and broadcasts its own SOTAcat-XXXX WiFi hotspot. Connect to it and follow Getting Started to set it up.

Firmware is served directly from this site's copy of the latest GitHub release. Need an older version, or a browser this page rejects? Use the command-line procedure.
